# list-to-do

Δημιουργήθηκε μια επαγγελματική σελίδα αναφοράς εκκρεμοτήτων για τα εισερχόμενα emails με θέμα "List to Do".

Πώς να το ανοίξετε:
- ανοίξτε το αρχείο `index.html` σε browser
- ή εξυπηρετήστε το repo με κάποιο local web server

Σημείωση:
- η περιοχή επικεφαλίδας είναι προετοιμασμένη για να χρησιμοποιήσει το αρχείο `assets/header.jfif` αν το προσθέσετε στο project
- μέχρι να προστεθεί η τελική εικόνα, εμφανίζεται fallback σχεδιασμός με επαγγελματική αισθητική

Αν θέλετε, μπορείτε να αντικαταστήσετε τα sample δεδομένα του αρχείου `app.js` με πραγματικά εισερχόμενα email του `grand.secretary@nglgreece.gr`.
